# PencilMaths-Admin

Admin application for managing PencilMaths modules: students, teachers, courses and questions.

- `npm start` — run on http://localhost:3000 (set `PORT` to change)
- `npm test` — run tests
- REST API: `GET /api`, and `GET|POST /api/:module`, `GET|PUT|PATCH|DELETE /api/:module/:id`

Data is stored in memory.
